Datacenter Architect for Linux (x86_64)

Start:    ./DatacenterArchitect.x86_64   (or double-click it)
Menu:     ./install.sh adds the game to your application menu (./install.sh --remove takes it out again)
Updates:  Info screen in the game (stable or test channel). Keep this folder somewhere your user may write,
          for example ~/Games/DatacenterArchitect; the updater replaces it and starts the new version.
Saves:    ~/.local/share/Datacenter Architect/saves  (logs in .../logs)
Needs:    a 64-bit Linux desktop (X11 or Wayland) with a Vulkan graphics driver (Mesa 22+ or the NVIDIA driver).

Nederlands: start ./DatacenterArchitect.x86_64; ./install.sh zet de game in je programmamenu. Updaten gaat via
het Info-scherm. Savegames staan in ~/.local/share/Datacenter Architect/saves.
